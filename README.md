# Robotic-Arm-Worst-Case
This repo describes the worst-case scenario for joint 2 of a 6 degress of freedom industrial robotic arm.

The worst case occurs when the robotic arm is in its fully extended position, the joint 2 is running at its maximum angular velocity carrying its maximum payload and must stop immediately within one second because of an emergency stop.

<img width="524" height="206" alt="image" src="https://github.com/user-attachments/assets/2e1743ec-7a42-4975-a1f9-1f71de8fb919" />


The code takes you through the assumptions and calculations steps for both the static and dynamic loads. At the end, an analysis is presented with the components with the highest effect on the total torque.
